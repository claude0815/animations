Vom Implementationsdiagramm zur Java-Klasse

Schritt für Schritt mit BlueJ — Attribute, Konstruktor, get/set & Methoden

1. Was ist ein Implementationsdiagramm?

Ein Implementationsdiagramm (eine ausführliche UML-Klassenkarte) beschreibt genau, wie eine Klasse aufgebaut ist. Es besteht aus drei Feldern, die übereinander liegen:

  1. Klassenname (oben)
  2. Attribute = die Daten / Eigenschaften (Mitte)
  3. Methoden = das Verhalten, inkl. Konstruktor, get- und set-Methoden (unten)

Schreibweise (Notation)

SymbolBedeutungJava
-private (nur innerhalb der Klasse sichtbar)private
+public (von überall sichtbar)public
name : TypAttribut mit Datentypprivate Typ name;
methode(Param) : TypMethode mit Parametern und Rückgabetyppublic Typ methode(...) { }
Faustregel: Attribute sind fast immer private (-), Methoden meist public (+). So sind die Daten geschützt und werden nur über get-/set-Methoden verändert (Datenkapselung).

2. Umsetzung Schritt für Schritt

Beispiel: die Klasse Auto. Klicke dich durch die Schritte – links siehst du das Diagramm (der aktuelle Teil ist markiert), rechts wächst der passende Java-Code mit.

3. Der Ablauf in BlueJ

  1. Neue Klasse anlegen: Button »Neue Klasse…« → Name Auto eingeben → Typ »Klasse«. BlueJ erzeugt ein Grundgerüst, das du löschst und durch deinen Code ersetzt.
  2. Code schreiben: Doppelklick auf das Klassen-Rechteck öffnet den Editor. Dort die Attribute, den Konstruktor und die Methoden eintragen.
  3. Übersetzen (kompilieren): Button »Übersetzen«. Schraffur auf dem Klassensymbol verschwindet, wenn alles fehlerfrei ist. Fehler erscheinen unten.
  4. Objekt erzeugen: Rechtsklick auf die Klasse → new Auto("B-AB 123", "VW"). Es entsteht eine rote Objektkarte auf der Werkbank (unten).
  5. Methoden testen: Rechtsklick auf das Objekt → Methode wählen, z. B. beschleunigen(30), danach getGeschwindigkeit() – das Ergebnis erscheint in einem Fenster.
Inspektor: Doppelklick auf die Objektkarte zeigt alle Attributwerte – ideal, um zu prüfen, ob Konstruktor und set-Methoden korrekt gearbeitet haben.

liest ein Attribut
public String getKennzeichen() { return kennzeichen; }

set-Methode

ändert ein Attribut
public void setKennzeichen(String k) { this.kennzeichen = k; }

enthält die Logik
public void beschleunigen(int wert) { geschwindigkeit += wert; }
